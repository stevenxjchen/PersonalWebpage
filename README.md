# Steven Chen · personal site

Live at **https://stevenxjchen.github.io**

A single-page introduction to Steven Chen (陈熙晋), a Cambridge A Level student in Mathematics, Further Mathematics, Physics and Chemistry at Guanghua Cambridge International School, Shanghai.

What's on the page:

- **Runway Overrun Awareness and Alerting System**: Steven's research project on cockpit alerting, with an interactive illustration of his three-level alert rules.
- **Projects**: a team rescue-robot concept, an HKU STEM racing-car project and the HKU × Intel robotics challenge.
- **Practice**: the things he keeps showing up for, including weekly volunteering at Ocean Heaven (海洋天堂) in Hangzhou since Grade 9, basketball, gym, tennis, volleyball and puzzles.
- **Results**: IGCSE and predicted A Level grades, IELTS, and competition results (SMC Gold, Physics Bowl Silver, BPhO Bronze, AMC 10 top 5%, AMC 12 top 25%).
- **Photos** and **contact**.

## About this repository

The site is one hand-written HTML file (`index.html`) plus the `img/` and `media/` folders. No framework, no build step, no tracking. It is served by GitHub Pages straight from this repository.

The alert rules shown on the page follow Steven's ROAAS design; the demo physics is simplified for illustration. Page designed and built with Claude, 2026.
